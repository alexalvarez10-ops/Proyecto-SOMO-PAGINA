# Centro de Formación Somorrostro — Rediseño Web RUTA A

Rediseño web interactivo y responsive para el **Centro de Formación Somorrostro** (San Juan 10, Muskiz).

## 🚀 Características
- **RUTA A**: Enfoque en oportunidad, compañerismo y aprendizaje práctico por retos (**Ethazi**).
- **Talleres de Informática**:
  - Montaje y Mantenimiento de Hardware
  - Redes Locales y Telecomunicaciones (Cisco & Fibra Óptica)
  - Creación y Desarrollo Web Moderno
- **Contador Interactivo en JavaScript**: Cuenta atrás dinámica para las 14:00 del viernes (cierre de sprints Ethazi).
- **Buscador en Vivo y Selector de Modos**: Filtro en tiempo real por tecnologías y selector de esquemas visuales.
- **Formularios Integrados**: Conectados al buzón institucional `alex.alvarez10@somo.eus`.
- **Widget Flotante**: *"Por favor deje su mensaje"* con controles interactivos.

## 🛠️ Tecnologías
- HTML5 Semántico
- CSS3 Moderno (Variables, Grid, Flexbox, Glassmorphism)
- JavaScript Vanilla ES6+
- Node.js (Servidor local integrado `server.js`)
